\paragraph{2.3.1.2 - Alcance}

El sistema se denominará ``CoConsorcio''.  
El sistema permitirá a los usuarios:
\begin{itemize}
    \item Gestionar usuarios   
    \item Gestionar departamentos   
    \item Gestionar contratos de alquiler   
    \item Registrar pagos y expensas   
    \item Gestionar reservas de espacios comunes   
    \item Gestionar visitas y paquetería   
    \item Publicar comunicados   
    \item Consultar documentación del consorcio   
    \item Gestionar información de propietarios e inquilinos 
\end{itemize}

El sistema estará disponible mediante una aplicación web accesible desde dispositivos con conexión a internet.
