\subsubsection{2.3.1 - Introducción}

El propósito de este documento es especificar los requerimientos funcionales y no funcionales del sistema CoConsorcio.  
El sistema permitirá administrar consorcios de edificios, facilitando la gestión de departamentos, propietarios, inquilinos, pagos, expensas, reservas y comunicación entre vecinos y administración.  

Este documento está dirigido a:
\begin{itemize}
    \item Administradores   
    \item Empleados administrativos   
    \item Propietarios   
    \item Inquilinos   
    \item Equipo de desarrollo
\end{itemize}
