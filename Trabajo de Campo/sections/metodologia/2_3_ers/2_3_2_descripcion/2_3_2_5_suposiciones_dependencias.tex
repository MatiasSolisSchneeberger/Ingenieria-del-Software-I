\paragraph{2.3.2.5 - Suposiciones y dependencias}

\begin{itemize}
    \item Disponibilidad permanente de conexión a internet.   
    \item Disponibilidad del servidor de alojamiento.   
    \item Correcto funcionamiento de la base de datos.   
    \item Disponibilidad de dispositivos compatibles con navegadores web.   
    \item Los usuarios deberán poseer credenciales válidas para acceder al sistema. 
\end{itemize}
