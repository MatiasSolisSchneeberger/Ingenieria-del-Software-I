\paragraph{2.3.2.4 - Restricciones}

\begin{itemize}
    \item El sistema deberá funcionar mediante conexión a internet.   
    \item El acceso requerirá autenticación de usuario.   
    \item El sistema deberá operar en navegadores web modernos.   
    \item El sistema utilizará una base de datos relacional.   
    \item El sistema será desarrollado utilizando tecnologías web.   
    \item El desarrollo del proyecto se realizará utilizando metodología Scrum. 
\end{itemize}
