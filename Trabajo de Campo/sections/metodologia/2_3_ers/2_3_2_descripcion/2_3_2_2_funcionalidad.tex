\paragraph{2.3.2.2 - Funcionalidad del Producto}

El sistema deberá permitir:
\begin{itemize}
    \item Gestión de usuarios   
    \item Gestión de departamentos   
    \item Gestión de propietarios e inquilinos   
    \item Gestión de pagos y expensas   
    \item Gestión de reservas de espacios comunes   
    \item Gestión de visitas y paquetería   
    \item Gestión de comunicados y documentación   
    \item Gestión de contratos de alquiler
\end{itemize}
