\subsubsection{2.3.2 - Descripción General}

\paragraph{2.3.2.1 - Perspectiva del producto}
CoConsorcio será un sistema independiente orientado a la administración de consorcios y alquileres de edificios.  
El sistema permitirá centralizar la información relacionada con:
\begin{itemize}
    \item Departamentos,   
    \item Propietarios,   
    \item Inquilinos,   
    \item Pagos,   
    \item Expensas,   
    \item Reservas,   
    \item Reclamos,   
    \item Comunicaciones internas. 
\end{itemize}

Los usuarios accederán mediante una interfaz web conectada a una base de datos centralizada.
